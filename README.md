# KazualCipher

**Готовый к повседневному использованию инструмент вокруг семейства
экспериментальных блочных шифров Kazual-512 / Kazual-64:**
пароль → Argon2id → аутентифицированный SIV-контейнер v2 (самоопределяемый,
с параллельным tree-MAC) или учебный ECB. Графический интерфейс, консоль,
пакетная обработка нескольких файлов и потоковое шифрование файлов любого
размера — от килобайт до десятков гигабайт — с постоянным потреблением ОЗУ
и загрузкой всех ядер CPU.

> ⚠️ **Честно о безопасности (единственное предупреждение).** Kazual —
> экспериментальная учебная конструкция: она не проходила независимого
> криптоанализа и не предназначена для защиты данных, которые вы не готовы
> потерять. Для боевых задач используйте проверенные стандарты
> (AES-GCM, ChaCha20-Poly1305). Подробности — вкладка «О шифре» и
> [`docs/specification.html`](docs/specification.html).

## Возможности (v1.1)

- **Большие файлы — без проблем.** Шифрование и расшифрование идут
  потоково: потребление ОЗУ постоянно (десятки МиБ) и не зависит от размера
  файла; проверка подлинности больших данных распараллелена (tree-MAC),
  CTR-поток считается JIT-кодом на всех ядрах CPU. Запись атомарна
  (`.part` → переименование), отмена безопасна (временный файл удаляется).
- **Нативное ускорение (numba JIT).** Ядра ГОРН-1024 и Kazual-512
  компилируются в машинный код и побитово идентичны эталонной реализации
  (проверяется тестами). Ускорение относительно v1.0 — на два-три порядка;
  без numba всё продолжает работать эталонным путём.
- **Несколько файлов за один раз.** Перетащите файлы в список (или добавьте
  папку целиком) — результат ляжет рядом с каждым источником (`.kaz`) или в
  выбранную папку; существующие имена не перезаписываются без согласия.
- **Самоопределяемый контейнер v2.** Файл сам хранит шифр, режим, параметры
  Argon2id, бренд-метку, состав полей и размер листа MAC. При расшифровке
  программа читает их из файла и **блокирует панель настроек** — больше
  нельзя «расшифровать не теми параметрами». Формат один-единственный:
  программа пишет и читает только его.
- **Простой и дружелюбный GUI.** Живая валидация полей (сырой ключ,
  фиксированная соль, бренд) вместо ошибок постфактум; карточка
  «что определено по файлу»; никаких налезающих друг на друга надписей.
- **Одно честное предупреждение** о статусе шифра — при первом запуске и на
  вкладке «О шифре». Назойливой рекламы опасности больше нет.
- **Система конфигураций.** Встроенные значения по умолчанию зашиты в код
  (сломать программу конфигом невозможно); пользовательский JSON
  подхватывается автоматически, его можно сохранить/загрузить/сбросить.
  Пароль не сохраняется никогда.
- **main.py сам ставит зависимости.** Запустили без окружения — программа
  сама откроет консоль установки, создаст `.venv`, поставит всё нужное,
  запустится и закроет консоль. Файлы `start.bat`/`start.sh` больше не
  нужны и удалены.
- **Новая иконка** — во всех размерах, включая `.ico` для Windows.
- Тонкая настройка не исчезла, а переехала в «Дополнительно» и «Настройки»:
  бренд-метка, params, random (только галочка: вкл — случайная соль,
  выкл — полный детерминизм), бэкенд (auto/native/NumPy/GPU/эталон),
  число потоков, размер листа tree-MAC, порог «в памяти», установка
  ускорителей кнопкой. Формат записи один — v2.

## Быстрый старт

Нужен **Python 3.9+** (проверено на 3.10–3.12), Windows / Linux / macOS.

### Двойной клик (или одна команда)

```bash
python main.py
```

Всё. Если зависимостей нет — `main.py` сам создаст `.venv`, сам установит
PySide6, NumPy, argon2-cffi и ускоритель numba (нужен интернет), сам
запустит программу и сам закроет консоль установки. При следующих запусках
программа стартует сразу, без консоли.

### Вручную (если хочется контролировать)

```bash
git clone <ваш-репозиторий> KazualCipher
cd KazualCipher
python -m venv .venv
# Linux/macOS: source .venv/bin/activate · Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install -r requirements-fast.txt   # ускорители (рекомендуется)
python main.py
```

### Консоль

```bash
python -m kazual                      # то же, что python main.py (GUI)
python -m kazual vectors              # тестовые векторы (§14 спецификации)
python -m kazual selftest             # полные самопроверки (~15 с)
python -m kazual bench                # замер скорости (эталон + native)

# один файл или сразу пачка (контейнер v2 создаётся автоматически):
python -m kazual enc --password "секрет" --input фото.jpg --input архив.zip
python -m kazual enc --password "секрет" --input big.iso --outdir защищено/
python -m kazual dec --password "секрет" --input защищено/big.iso.kaz

# тонкая настройка из терминала:
python -m kazual enc --text "привет" --key-hex deadbeefcafebabe \
    --no-random --brand "мой-бренд/v2" --kdf 65536,3,4 --threads 8
# колёсико мыши в GUI значения не меняет — только навигация
```

## Скорость: чего ждать

Узким местом должно быть ваше железо, а не программа — поэтому:

| этап | как распараллелено | порядок величин (многоядерный CPU) |
|---|---|---|
| tree-MAC (подлинность) | все ядра, листья по 4 МиБ | сотни МиБ/с |
| CTR (шифрограмма) | numba prange, все ядра | сотни МиБ/с |
| Argon2id (ключ) |	argon2-cffi, p дорожек | доли секунды (пресет) |
| расписание ключа | кэш LRU на ключ | ~0.1–0.5 с, повторно — мгновенно |
| дисковые проходы | последовательное чтение/запись | скорость вашего диска |

10 ГиБ в SIV — это два прохода чтения и один записи плюс MAC/CTR поверх:
на современном SSD и 8–16-ядерном CPU порядка нескольких минут. Память при
этом не раздувается: очереди ограничены несколькими сегментами.

Замер на своей машине: `python -m kazual bench` (покажет и эталонный путь
для сравнения, и native, и tree-MAC). GPU (CuPy) поддерживается опционально
(`--backend gpu` / Настройки → GPU), но для данного шифра многоядерный CPU
обычно не медленнее: раундовая функция состоит из тысяч коротких табличных
операций, которые плохо ложатся на тысячи лёгких GPU-потоков.

## Конфигурация

Все конфиги лежат **внутри папки программы**: `KazualCipher/configs/`.

- `configs/default.json` — конфиг по умолчанию, загружается при старте;
- всё состояние программы (настройки, вкладка, правила вывода, размер и
  развёрнутость окна) сохраняется **автоматически и в реальном времени**
  в текущий конфиг;
- «Сохранить как…» — снимок состояния под своим именем (профили);
  «Загрузить» — применить профиль; «Сделать по умолчанию» — он будет
  загружаться при старте; «Сбросить к встроенным» — значения из кода
  применяются к виджетам сразу и сохраняются;
- повреждённый файл не фатален: переименовывается в `*.broken`, стартуем со
  встроенных значений; пароль не сохраняется никогда.

## Формат пакета v2 (кратко)

```
magic ‖ ver ‖ cipher ‖ mode ‖ flags ‖ brand ‖ [params] ‖ [random]
      ‖ leaf_size ‖ total_len ‖ V ‖ шифрограмма
```

`V` — корень tree-MAC: листья (по `leaf_size` байт) хэшируются ГОРНом
независимо и параллельно, корень впитывает их дайджесты вместе с полями
заголовка и `K_mac`. Любая подмена байта файла рвёт `V`. Полное описание —
[`docs/packet-format.md`](docs/packet-format.md), спецификация шифра —
[`docs/specification.html`](docs/specification.html).

## Структура проекта

```
main.py                  точка входа: GUI + автоустановка зависимостей
kazual/
  cipher/                эталонная реализация шифров (§1–§12 спецификации)
    native.py            numba JIT: ГОРН и Kazual-512 в машинном коде
  modes/                 контейнер v2, SIV (+tree-MAC), ECB, CTR, PKCS#7
  stream.py              потоковые конвейеры файлов, пакеты, отмена, .part
  config.py              конфигурации (JSON + встроенные значения)
  kdf.py / keys.py       Argon2id + вывод ключей
  engine.py              фасад «настройки → данные → результат»
  cli.py                 консоль: python -m kazual …
  app/                   GUI на PySide6: тема, сайдбар, страницы, воркеры
tests/                   pytest-набор (для разработки, не для пользователя)
docs/                    формат пакета и спецификация шифра
assets/                  иконка (svg/png/ico) и скриншоты
```

## Тесты

```bash
pip install -r requirements-dev.txt
pytest                 # основной набор + native + стриминг + GUI-смоук
pytest -m slow         # полные самопроверки эталона
pytest -m gui          # только GUI (offscreen)
```

Покрыто: побитовое совпадение native-ядер с эталоном; тестовые векторы
спецификации; раундтрипы во всех комбинациях полей; тамперинг
каждого поля и каждого байта файла; независимость tree-MAC от числа
потоков; атомарность записи и очистка `.part` при отмене; пакетные
операции и коллизии имён; конфиги (порча, слияние, санитизация); смоук GUI
с автоопределением файла и блокировкой панели.
