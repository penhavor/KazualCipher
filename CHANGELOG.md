## [1.1.1] — 2026-10-18

### Изменено

- Конфиги переехали внутрь папки программы: `KazualCipher/configs/`
  (default.json загружается при старте; именованные профили — снимки
  состояния). Автосохранение теперь в реальном времени и покрывает всё
  состояние, включая вкладку, правила вывода и геометрию окна
  (размер/позиция/развёрнутость/полный экран). Старый конфиг из
  пользовательского каталога переносится один раз автоматически.
- «Сбросить к встроенным» починен: значения теперь действительно
  применяются к виджетам (раньше кнопка не обновляла панель).
- Один формат записи — v2; выбор формата убран из интерфейса и CLI.
- random упрощён до галочки: включено — случайная соль на каждый файл,
  выключено — полный детерминизм; поле ручного ввода hex-соли убрано.
- Колёсико мыши больше не меняет значения спинбоксов и комбобоксов —
  только навигация/прокрутка.
- Windows: в панели задач отображается иконка программы (раньше — значок
  python.exe).
- Кнопки установки ускорителей показывают факт: «Обновить numba
  (установлена ✓)» / «Установить … — СЕЙЧАС НЕ СТОИТ!» с пояснением, что
  numba ставится автоматически при первом запуске main.py.

### Починено

- Блокировка панели «параметры из файла» действовала на всех вкладках —
  теперь только на «Расшифрование», при возврате восстанавливается.
- Сайдбар больше не расползается под скроллбар (длинные неподпереносимые
  подписи чекбоксов, комбобок формата); кнопка показа пароля не обрезается.
- Тест: убран флейк test_gorn_hasher_equals_oneshot (0x1F в случайном теге).

## [1.1.0] — 2026-10-18

Релиз «продукт, а не прототип»: скорость, большие файлы, пакетная
обработка, самоопределяемый формат, конфиги и полировка GUI.

### Добавлено

- **Нативное ускорение (numba JIT)**: `kazual/cipher/native.py` — ядра
  ГОРН-1024 и Kazual-512 (блок, CTR) компилируются в машинный код,
  побитово идентичны эталону (проверяется тестами), параллельны по всем
  ядрам CPU; ускорение на два-три порядка относительно v1.0. Без numba
  всё работает прежними путями (NumPy/эталон).
- **Параллельный tree-MAC** для больших сообщений: листья по `leaf_size`
  хэшируются пулом потоков (nogil), корень — последовательно; результат не
  зависит от числа потоков.
- **Потоковая обработка файлов любого размера** (`kazual/stream.py`):
  постоянное потребление ОЗУ (сегменты ~8 МиБ + очереди листьев), два
  прохода при шифровании SIV (MAC, затем CTR) и один при расшифровке
  (CTR + MAC по пути); атомарная запись через `.part` + `os.replace`;
  отмена между сегментами с удалением временного файла. 10 ГиБ больше не
  требуют 10 ГиБ ОЗУ и суток времени.
- **Пакетная обработка**: несколько файлов (и целые папки) за одну
  операцию, drag&drop списка, правила вывода («рядом с источником» /
  «в папку»), защита от перезаписи (свободные имена «… (1)»), отчёт по
  каждому файлу; ошибка одного файла не прерывает пакет.
- **Контейнер v2** (`kazual/modes/container.py`): самоопределяемый формат
  `magic‖ver‖cipher‖mode‖flags‖brand‖[params]‖[random]‖leaf_size‖total_len‖V‖payload`.
  При расшифровке шифр, режим, параметры Argon2id и состав полей читаются
  ИЗ файла; GUI блокирует панель настроек (карточка «параметры из файла»).
- **Система конфигураций** (`kazual/config.py`): встроенные значения по
  умолчанию в коде; автоконфиг JSON (пользовательский каталог или
  портативный `config.json` рядом с программой); сохранить/загрузить/
  сбросить; повреждённый файл → `*.broken` + дефолты. Пароль не
  сохраняется никогда.
- **main.py сам ставит зависимости**: при нехватке открывает консоль
  установки, создаёт `.venv`, ставит PySide6/NumPy/argon2-cffi (+numba),
  запускает программу и закрывает консоль; на Windows GUI стартует без
  висящей консоли. `start.bat`/`start.sh` удалены.
- Страница «Настройки»: статус ускорителей, бэкенд (auto/native/cpu/gpu/
  scalar), потоки, лист tree-MAC, порог «в памяти», установка numba/CuPy
  кнопкой из программы.
- Новая иконка (svg + png + ico), живая валидация полей ввода (сырой ключ,
  фиксированная соль, бренд), карточка автоопределения формата.
- CLI: пачка файлов (`--input a b c`, `--outdir`), `--threads`,
  `--backend`, `--brand`, `--v1`, `--leaf-mib`, `--overwrite`;
  `bench` показывает native-замеры.

### Изменено

- GUI переработан: простой сайдбар (шифр/режим/ключ/KDF + сворачиваемое
  «Дополнительно»), убраны налезания текста и фикс-высоты; предупреждения
  о небезопасности сведены к одному полному тексту (первый запуск +
  «О шифре»); функциональные примечания остались компактными строками.
- Ошибка «фиксированный random» больше не появляется постфактум: поле
  валидируется на лету с зелёной/красной подсказкой.
- ECB получил контейнер v2 (самоописание KDF).
- Расписание ключей кэшируется (LRU по ключу) — пакетные операции не
  платят 0.5 с за каждый файл повторно.
- MAC и растягивание сырых ключей ускорены нативным ГОРНом.

### Совместимость

- Python 3.9+; numba необязательна (ускоритель деградирует gracefully).

## [1.0.0] — 2026-10-18
Первый публичный релиз: монолитная эталонная реализация превращена в
пакет `kazual.cipher` (побитово идентична исходнику, все самопроверки и
тестовые векторы проходят) и обёрнута в полноценный продукт.

### Добавлено

- GUI на PySide6: выбор шифра (Kazual-512 / Kazual-64) и режима
  (SIV / ECB) списками; источники ключа (пароль Argon2id с пресетами и
  ручными m/t/p, сырой hex-ключ); тонкая настройка полей SIV-пакета
  галочками (prefix со своим текстом, params со своими параметрами KDF,
  random с фиксированным значением); вкладки «Шифрование»,
  «Расшифрование», «Пакет» (живая схема + разбор примера по байтам),
  «О шифре»; текст Base64/HEX и файлы в обе стороны; прогресс, отмена,
  понятные ошибки и предупреждения; сохранение настроек между запусками
  (пароль не сохраняется никогда).
- Режим SIV: пакет `prefix + params + random + V + шифрограмма`;
  V = ГОРН-MAC от всех полей и текста (синтетический nonce CTR + тег
  подлинности); самоописание KDF через PHC-строку в поле params.
- Режим ECB: независимые блоки + PKCS#7, с честными предупреждениями.
- Консоль `python -m kazual …`: enc/dec с теми же настройками, selftest,
  vectors, trace, bench.
- Тесты pytest: векторы спецификации, эквивалентность NumPy/скаляр,
  раундтрипы SIV при всех комбинациях галочек, тамперинг каждого поля,
  границы Argon2, смоук GUI; CI-workflow GitHub Actions.
- Документация: README, docs/packet-format.md, спецификация шифра
  docs/specification.html.
- Лаунчеры первого запуска: `start.bat` (Windows) и `start.sh`
  (Linux/macOS) — сами создают `.venv` и ставят зависимости; `main.py`
  при нехватке зависимостей больше не закрывает консоль мгновенно, а
  печатает пошаговую инструкцию и ждёт Enter.

### Изменено

- Однофайловый эталон разбит на модули `kazual/cipher/*` без изменения
  поведения (все 30+ самопроверок и тестовые векторы проходят без правок
  ожидаемых значений).
- Добавлен инкрементальный хэшер ГОРН (`GornHasher`) для потокового MAC;
  побитово равен однопроходному `gorn_hash`.
