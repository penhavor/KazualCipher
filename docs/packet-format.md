# Формат SIV-пакета Kazual (v1)

Байтовый макет (конкатенация строгая, больших-endian):

```
packet = prefix ‖ params ‖ random ‖ V ‖ ciphertext
```

| поле | ширина | содержимое | присутствие |
|---|---|---|---|
| `prefix` | 32 Б | `89 4B 5A 4C` («магические байты» ‰KZL) + UTF-8-текст бренда/версии (по умолчанию `Kazual-512/v1.0` или `Kazual-64/v1.0`), дополнено `0x00` до 32 Б | опционально (галочка) |
| `params` | 2 + L Б | `u16be(L)` + ASCII PHC-строка `$argon2id$v=19$m=…,t=…,p=…` | опционально (галочка) |
| `random` | 32 Б | соль Argon2id / антиповторный nonce; `os.urandom` или фиксированное значение | опционально (галочка; выкл → соль `0x00×32`) |
| `V` | 64 Б | тег: `ГОРН(K_mac ‖ body, tag=домен)` — см. ниже | всегда |
| `ciphertext` | = |тексту| | `CTR(K_enc, IV=V[:block] с зоной счётчика, counter)` | всегда |

## Ключи

- пароль: `master = Argon2id(password, salt=random‖0×32, PHC-параметры, 2·ks)`;
- сырой ключ: `master = gorn_expand(key, TAG‖'/SIV-RAWKEY/'‖cipher, 2·ks)`;
- `K_enc = master[:ks]`, `K_mac = master[ks:]`, где `ks` — длина ключа шифра
  (64 Б для Kazual-512, 8 Б для Kazual-64).

## Тег V (MAC)

ГОРН-1024 — губка с ёмкостью 512 бит, поэтому конструкция
«ключ ‖ сообщение» не удлиняема и HMAC не нужен. Доменное разделение —
тегом хэша: `KazualCipher/SIV/v1/<имя шифра>`.

Каноническое тело (каждое поле с u32be-длиной, порядок фиксирован,
отключённые поля входят пустыми; длина текста — отдельным u64be-полем
ПЕРЕД текстом):

```
body = u32(len prefix) ‖ prefix
     ‖ u32(len params) ‖ params
     ‖ u32(len random) ‖ random
     ‖ u64(len plaintext) ‖ plaintext
V = gorn_hash(K_mac ‖ body, tag='KazualCipher/SIV/v1/' + cipher)
```

## CTR

`IV = V[:block_bytes]`, младшие `counter_bytes` байт — счётчик
(8 Б при блоке ≥ 16 Б, иначе половина блока); старший бит зоны счётчика
обнуляется (приём RFC 5297 Q). Счётчик big-endian, начинается с 0.
Блоки независимы, паддинга нет.

## Проверка при расшифровке

1. разобрать поля по текущим галочкам (несовпадение макета даёт понятную
   ошибку формата; магические байты подсказывают про включённый `prefix`);
2. параметры KDF берутся ИЗ ПАКЕТА, если поле `params` присутствует,
   иначе — из текущих настроек;
3. `plaintext = CTR-decrypt(K_enc, V, ciphertext)`;
4. пересчитать `V'` и сравнить с `V` за постоянное время
   (`hmac.compare_digest`); несовпадение = неверный пароль / порча /
   другие галочки.

## ECB (без контейнера)

`ciphertext = E_blocks(K_enc, PKCS#7(plaintext))`; дополнение снимается с
проверкой корректности (ошибка = неверный ключ или порча, но БЕЗ гарантии
целостности — MAC в режиме нет). Ключ: пароль с нулевой солью и текущими
PHC-параметрами либо `gorn_expand(key, TAG‖'/ECB-RAWKEY/'‖cipher, ks)`.
