# Формат контейнера Kazual (v2)

Единственный формат записи программы. Контейнер **самоописуем**: всё, что
нужно для расшифровки (кроме пароля/ключа), лежит в заголовке — угадывать
при расшифровке ничего не нужно, GUI читает параметры из файла и
блокирует панель настроек.

Контейнер v2 **самоописуем**: всё, что нужно для расшифровки (кроме
пароля/ключа), лежит в заголовке. Набор «галочек» при расшифровке больше
не нужен; GUI читает параметры из файла и блокирует панель.

## Макет заголовка (big-endian)

```
смещение  поле        размер  содержание
0         magic       4       89 4B 5A 4C  («‰KZL»)
4         ver         1       = 2
5         cipher_id   1       0 = Kazual-512, 1 = Kazual-64
6         mode        1       0 = SIV, 1 = ECB
7         flags       1       bit0 params · bit1 random · bit2 tree-MAC
8         brand_len   1       0…255
9         brand       n       UTF-8 метка владельца/версии (опционально)
…         params      2+n     u16be длина + PHC-строка (если flags bit0)
…         random      32      соль/nonce Argon2id (если flags bit1)
…         leaf_size   4       u32: байт в листе tree-MAC (только SIV)
…         total_len   8       u64: точная длина открытых данных
…         V           64      тег подлинности = корень tree-MAC (только SIV)
…         payload     …       SIV: CTR-шифрограмма total_len байт;
                              ECB: блоки с PKCS#7 (кратно блоку шифра)
```

Служебные поля SIV v2: 9 + brand + (2+len(PHC)) + 32 + 4 + 8 + 64 байт
(≈150–190 Б). ECB v2: то же без leaf_size и V.

## Tree-MAC (подлинность больших данных, параллельно)

```
n      = max(1, ⌈total_len / leaf_size⌉)              (пусто → 1 пустой лист)
d_i    = ГОРН( лист_i ;  tag = «KazualCipher/SIV/v2/leaf/» ‖ cipher
                            ‖ u64be(i) ‖ u64be(total_len) )
V      = ГОРН( K_mac ‖ frame(brand, params, random)
               ‖ u64be(total_len) ‖ u32be(leaf_size) ‖ u32be(n)
               ‖ d_0 ‖ … ‖ d_{n-1} ;
               tag = «KazualCipher/SIV/v2/root/» ‖ cipher )
frame(…)  — по каждому полю u32be(длина) ‖ байты (как в v1)
```

Листья независимы — хэшируются пулом потоков (нативное ядро отпускает GIL),
порядок впитывания дайджестов в корень строго по индексу, поэтому V не
зависит от числа потоков. Криптостойкость: коллизии 512-битного ГОРНа +
ключ только в корне.

CTR, вывод ключей (Argon2id с солью из `random` или нулевой при
отключённом random) и доменные теги — без изменений относительно v1.

## Проверки при разборе

- magic/ver/cipher/mode/flags валидируются явно (ошибка формата с текстом);
- `total_len` сверяется с фактическим размером файла (обрезка видна сразу);
- ECB-payload обязан быть кратен блоку шифра;
- после дешифрования V пересчитывается по открытому тексту; несовпадение —
  MacError, временный файл удаляется, пользователь не получает
  непроверенные данные.
